# Contributing to TinyBus

TinyBus owns the portable service bus, module ABI, admission, and lifecycle
contracts. Keep changes focused and include regression coverage for behavior
changes.

## Shared Module CI and Releases

TinyBus follows the shared module CI and release contract maintained in
[tinyhumansai/.github](https://github.com/tinyhumansai/.github/blob/main/docs/module-ci-contract.md).
